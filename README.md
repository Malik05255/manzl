# مترجم الأفلام

تطبيق Android مستقل لترجمة الأفلام التركية إلى العربية على الجهاز.

## ماذا يفعل؟

- اختيار فيلم من ذاكرة الجهاز عبر Android Storage Access Framework.
- فك المسار الصوتي فقط باستخدام MediaCodec بدون إعادة ترميز الفيديو.
- تحويل الكلام التركي إلى نص محليًا باستخدام Vosk ونموذج `vosk-model-small-tr-0.3`.
- ترجمة النص من التركية إلى العربية على الجهاز باستخدام ML Kit Translation.
- إنشاء ملف SRT عربي.
- تشغيل الفيديو الأصلي داخل التطبيق مع ملف الترجمة الناتج عبر Media3/ExoPlayer.
- حفظ ملف SRT في أي مكان يختاره المستخدم.

بعد تنزيل نموذج Vosk ونماذج ML Kit في أول استخدام، المعالجة نفسها تتم محليًا ولا يُرفع الفيلم إلى خادم.

## البناء

```bash
./gradlew :translator-app:assembleDebug
```

APK:

`translator-app/build/outputs/apk/debug/translator-app-debug.apk`

## المتطلبات

- Android 10 أو أحدث (`minSdk 29`).
- اتصال إنترنت في أول استخدام لتنزيل نماذج اللغة فقط.
