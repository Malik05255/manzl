# مترجم الأفلام

تطبيق Android مستقل لترجمة الأفلام التركية إلى العربية بواجهة عربية بسيطة.

## تجربة الاستخدام

1. اختر الفيلم من الجهاز.
2. اضغط **ابدأ الترجمة**.
3. اترك التطبيق يكمل تلقائيًا في الخلفية.
4. شاهد الفيلم مع الترجمة العربية أو احفظ ملف SRT.

لا توجد شاشة إعداد مفاتيح أو إعدادات تقنية للمستخدم. مفاتيح مزودي المعالجة السرية تبقى في بيئة Supabase Edge Functions ولا تُضمّن داخل التطبيق.

## كيف تعمل المعالجة؟

- الفيديو الأصلي لا يُرفع إلى الخادم.
- يستخرج التطبيق نسخة صوتية مؤقتة ومحسّنة للكلام باستخدام FFmpegKit.
- التعرف على الحوار التركي يتم سحابيًا عبر Groq Whisper مع مسار Gemini الاحتياطي.
- الترجمة التركية إلى العربية تتم باستخدام سياق الحوار الكامل ثم تمر بمراجعة دقة.
- يُنشأ ملف SRT عربي ويُربط بالفيديو الأصلي أثناء التشغيل عبر Media3 / ExoPlayer.
- المهام السحابية الطويلة تُستكمل عبر WorkManager ويمكنها مواصلة العمل بعد إخفاء التطبيق.

## الشبكة والأخطاء

يفرق التطبيق بين انقطاع الإنترنت الفعلي وبين تأخر أو تعطل خدمة الترجمة. عند وجود اتصال صالح لا تُعرض رسالة مضللة تفيد بأن الشبكة مقطوعة، وتتم إعادة المحاولة تلقائيًا للحالات المؤقتة.

## البناء والتحقق

```bash
./gradlew :translator-app:assembleDebug
./gradlew :translator-app:testDebugUnitTest
./gradlew :translator-app:lintDebug
```

APK:

`translator-app/build/outputs/apk/debug/translator-app-debug.apk`

## المتطلبات

- Android 10 أو أحدث (`minSdk 29`).
- اتصال إنترنت أثناء تنفيذ الترجمة السحابية.
